
Study Session Timer
A simple, good-looking web timer for long study days. It splits a 9-hour day into three 3-hour sessions and guides you through each one, so you can focus on learning instead of watching the clock.
How each session works
Every session has three blocks, one after the other:
• Watch the video for 30 minutes
• Take notes for 30 minutes
• Solve questions for 2 hours (at least two questions)
That makes 3 hours per session, and 9 hours across all three.
Features
• Countdown ring for the current block, plus total study time so far
• Beep and notification when a block ends, then the next block starts on its own
• Stops at the end of each session so you can rest before starting the next
• One break per session, with a length you choose (10 minutes by default). Study time pauses during the break and resumes automatically
• Skip to the next block early with Done, next
• Progress is saved in your browser, so refreshing the page won't lose your place
• Works on laptop and phone, with light and dark themes
How to use it
1.  Open the live page (add your link here).
2.  Press Start and begin with the video block.
3.  Keep the tab open while you study. On a phone, turn off auto-lock so the screen stays awake.
4.  Allow notifications when asked, and keep your volume up so you hear the end-of-block beep.
Notes
• Progress is stored separately on each device, so a laptop and a phone will not sync.
• Closing the tab stops the timer.
Built with
Plain HTML, CSS and JavaScript in a single file, with no libraries or build step. Hosted on GitHub Pages.
Run it locally
Download index.html and double-click it to open it in your browser.
